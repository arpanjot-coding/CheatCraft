Before you start

What do I need to run CheatCraft?

Windows x64 and 64-bit Python 3.11 or newer with Tcl/Tk. Download the source, run Setup.cmd, then Launch.cmd. Local checks used Python 3.14.7.

Which processes can I inspect?

Processes you own or have permission to inspect, when Windows grants read access. CheatCraft does not bypass anti-cheat or process protections.
