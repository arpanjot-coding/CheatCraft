시작하기 전에

실행하려면 무엇이 필요한가요?

Windows x64와 Tcl/Tk가 포함된 64비트 Python 3.11 이상이 필요합니다. 소스를 다운로드하고 Setup.cmd, Launch.cmd 순서로 실행하세요. 로컬 검증에는 Python 3.14.7을 사용했습니다.

어떤 프로세스를 검사할 수 있나요?

직접 소유하거나 검사 권한이 있는 프로세스 중 Windows가 읽기 접근을 허용하는 프로세스입니다. 안티치트나 프로세스 보호를 우회하지 않습니다.
