Avant de commencer

Que faut-il pour lancer l’application ?

Windows x64 et Python 64 bits, version 3.11 ou ultérieure, avec Tcl/Tk. Téléchargez le code, lancez Setup.cmd, puis Launch.cmd. Les vérifications locales utilisent Python 3.14.7.

Quels processus puis-je examiner ?

Vos processus ou ceux que vous êtes autorisé à examiner, si Windows accorde un accès en lecture. CheatCraft ne contourne ni les systèmes anti-triche ni les protections des processus.
