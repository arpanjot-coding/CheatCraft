Vor dem Start

Was benötige ich zum Ausführen?

Windows x64 und 64-Bit-Python ab Version 3.11 mit Tcl/Tk. Lade den Quellcode herunter und starte zuerst Setup.cmd, dann Launch.cmd. Lokal wurde mit Python 3.14.7 getestet.

Welche Prozesse darf ich untersuchen?

Eigene Prozesse oder solche, für die eine Erlaubnis vorliegt, sofern Windows Lesezugriff gewährt. CheatCraft umgeht weder Anti-Cheat-Systeme noch Prozessschutz.
