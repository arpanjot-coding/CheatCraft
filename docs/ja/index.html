使い始める前に

実行に必要な環境は？

Windows x64と、Tcl/Tkを含む64ビット版Python 3.11以降が必要です。ソースをダウンロードし、Setup.cmd、Launch.cmdの順に実行します。ローカル検証にはPython 3.14.7を使用しました。

どのプロセスを調べられますか？

自分が所有する、または調査を許可されたプロセスで、Windowsが読み取りを許可するものです。アンチチートやプロセス保護を回避する機能はありません。
