สำหรับนักพัฒนาเกมและผู้ทดสอบทางเทคนิค

ก่อนเริ่มใช้งาน

ต้องใช้อะไรในการเรียกใช้แอป?

ต้องมี Windows x64 และ Python 64 บิต เวอร์ชัน 3.11 ขึ้นไปพร้อม Tcl/Tk ดาวน์โหลดซอร์สแล้วเรียกใช้ Setup.cmd ตามด้วย Launch.cmd การตรวจสอบในเครื่องใช้ Python 3.14.7

ตรวจสอบโปรเซสใดได้บ้าง?

โปรเซสที่คุณเป็นเจ้าของหรือได้รับอนุญาตให้ตรวจสอบ โดย Windows ต้องอนุญาตให้อ่านได้ CheatCraft ไม่ได้ข้ามระบบป้องกันการโกงหรือการป้องกันโปรเซส
