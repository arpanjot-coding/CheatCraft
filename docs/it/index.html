Prima di iniziare

Cosa serve per usare CheatCraft?

Windows x64 e Python a 64 bit, versione 3.11 o successiva, con Tcl/Tk. Scarica il codice, esegui Setup.cmd e poi Launch.cmd. I test locali usano Python 3.14.7.

Quali processi posso analizzare?

Processi tuoi o che sei autorizzato ad analizzare, se Windows concede l’accesso in lettura. CheatCraft non aggira sistemi anti-cheat né protezioni dei processi.
