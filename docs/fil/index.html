Bago magsimula

Ano ang kailangan para patakbuhin ito?

Windows x64 at 64-bit Python 3.11 o mas bago na may Tcl/Tk. I-download ang source, patakbuhin ang Setup.cmd, at pagkatapos ang Launch.cmd. Python 3.14.7 ang ginamit sa lokal na pagsusuri.

Aling mga process ang maaari kong suriin?

Mga process na pag-aari mo o pinahihintulutan kang suriin, kung nagbibigay ang Windows ng read access. Hindi nilalampasan ng CheatCraft ang anti-cheat o proteksiyon ng process.
