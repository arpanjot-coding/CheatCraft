开始之前

运行 CheatCraft 需要什么？

需要 Windows x64，以及包含 Tcl/Tk 的 64 位 Python 3.11 或更高版本。下载源码后依次运行 Setup.cmd 和 Launch.cmd。本地验证使用 Python 3.14.7。

可以检查哪些进程？

在 Windows 授予读取权限的前提下，检查你拥有或获准检查的进程。CheatCraft 不会绕过反作弊或进程保护。
