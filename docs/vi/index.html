v0.4.0 / source preview

v0.4.0 là bản xem trước mã nguồn và cần Python. Tệp thực thi chưa ký không được phân phối vì bị chặn khởi chạy khi kiểm tra cục bộ.

Trước khi bắt đầu

Cần gì để chạy ứng dụng?

Windows x64 và Python 64 bit phiên bản 3.11 trở lên có Tcl/Tk. Tải mã nguồn, chạy Setup.cmd rồi Launch.cmd. Kiểm tra cục bộ sử dụng Python 3.14.7.

Tôi có thể kiểm tra tiến trình nào?

Tiến trình bạn sở hữu hoặc được phép kiểm tra, khi Windows cấp quyền đọc. CheatCraft không vượt qua hệ thống chống gian lận hoặc bảo vệ tiến trình.
