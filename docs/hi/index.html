शुरू करने से पहले

इसे चलाने के लिए क्या चाहिए?

Windows x64 और Tcl/Tk सहित 64-बिट Python 3.11 या नया संस्करण चाहिए। सोर्स डाउनलोड करें, फिर Setup.cmd और Launch.cmd चलाएँ। स्थानीय जाँच Python 3.14.7 पर हुई है।

किन प्रोसेस की जाँच कर सकते हैं?

वे प्रोसेस जिनके आप मालिक हैं या जिनकी जाँच की अनुमति है, और जिन तक Windows पढ़ने की पहुँच देता है। CheatCraft एंटी-चीट या प्रोसेस सुरक्षा को बायपास नहीं करता।
