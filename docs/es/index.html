Antes de empezar

¿Qué necesito para ejecutarlo?

Windows x64 y Python de 64 bits, versión 3.11 o posterior, con Tcl/Tk. Descarga el código, ejecuta Setup.cmd y después Launch.cmd. Las pruebas locales usan Python 3.14.7.

¿Qué procesos puedo inspeccionar?

Procesos propios o que tengas permiso para inspeccionar, si Windows concede acceso de lectura. CheatCraft no elude sistemas antitrampas ni protecciones de procesos.
